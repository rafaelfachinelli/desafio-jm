## :information_source: About

🎁 A small quiz page made as a gift for a friend from a Twitch community. Two questions about moments of the live streams have to be answered correctly to unlock the gift; until then it stays blocked. A looping video plays in the background, and a help button explains the challenge.

Built in 2021 with plain HTML, CSS and JavaScript.
